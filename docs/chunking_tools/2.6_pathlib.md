## 1. Paths as objects

```python
from pathlib import Path

path = Path('data/raw/vllm-0.10.1/docs/serving/api.md')
print(path.name)       # api.md
print(path.suffix)     # .md
print(path.parent)     # data/raw/vllm-0.10.1/docs/serving
print(path.as_posix()) # data/raw/vllm-0.10.1/docs/serving/api.md
```

`Path` provides operating-system-aware path operations. `as_posix()` outputs forward slashes.

## 2. Listing corpus files

```python
from pathlib import Path

root = Path('data/raw')
for path in sorted(root.rglob('*')):
    if path.is_file():
        print(path.as_posix())
```

`rglob('*')` searches recursively. `sorted()` makes the processing order deterministic, which helps when debugging and comparing runs. A very large corpus may contain generated or irrelevant files: choose extensions deliberately.

The 42 subject requires **distinct Python and Markdown/text chunking strategies**. It does not require every file extension to be indexed. Your choice should be explained in the README and evaluated against recall scores.

## 4. Preserving the exact relative path

For the 42 evaluation, `MinimalSource.file_path` must match the ingested corpus path relative to the **project root** exactly; a changed prefix can make a correct result score as incorrect.

```python
from pathlib import Path

project_root = Path.cwd()
absolute_path = project_root / 'data/raw/vllm-0.10.1/docs/serving/api.md'
relative_path = absolute_path.relative_to(project_root)
print(relative_path.as_posix())
# data/raw/vllm-0.10.1/docs/serving/api.md
```

**Important:** `Path.cwd()` works here because the command is run from the repository root. For robust code, explicitly establish or configure the project root; do not assume the working directory is always correct. Avoid returning just `docs/serving/api.md`, because it loses the `data/raw/...` prefix.

## 5. Reading files without shifting offsets

```python
from pathlib import Path

path = Path('data/raw/example.py')
with path.open('r', encoding='utf-8', newline='') as file:
    text = file.read()
```

Character offsets are computed over the **decoded text**, not the number of bytes. `newline=''` keeps the original line-ending characters (`\r\n` stays `\r\n`) instead of silently translating them to `\n`.

This is important because changing line endings shifts every later offset. Handle UTF-8 decoding errors or unreadable files per file so one problem does not crash the entire index operation.

## 6. Errors and reproducibility

Potential failures include `FileNotFoundError`, `PermissionError`, and `UnicodeDecodeError`. Use narrow exception handlers, report why a file was skipped, and keep processing the other files.

Indexing is allowed at most **5 minutes** on the full corpus (subject, Chapter VII), so measure the whole pipeline instead of guessing whether scanning and splitting are fast enough.

Keep I/O separate from pure chunking logic:

```text
indexer.py: walk files -> read original text -> select strategy
chunking.py: text + max_size -> ranges in that original text
models.py: create Chunk / MinimalSource instances
```

The exact ownership of `Chunk` construction is your design choice; the important part is that every source range refers to the original file.
