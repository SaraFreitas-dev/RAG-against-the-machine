# 2.5 — `textwrap`: Formatting Text Without Breaking Source Offsets

## 1. What `textwrap` does

`textwrap` wraps and reformats strings. It is built into Python, so no installation is necessary.

```python
import textwrap

sentence = 'A model retrieves the most relevant pieces of a codebase.'
print(textwrap.wrap(sentence, width=20))
```

This returns a list of wrapped strings. Formatting **changes the text**, so you must not assume positions in the formatted result match positions in the original file.

## 2. `wrap()` and `fill()`

```python
import textwrap

text = 'This is a long sentence that will be displayed in a narrow terminal.'
print(textwrap.wrap(text, width=25))  # list[str]
print(textwrap.fill(text, width=25))  # str with inserted newlines
```

`wrap()` produces multiple lines; `fill()` joins them with newline characters. They are useful for reports and console output, **not** for preserving original chunk offsets.

## 3. `dedent()`

```python
from textwrap import dedent

source = """\
    def hello():
        return 'hello'
"""
print(dedent(source))
```

`dedent()` removes common indentation. This is convenient for toy examples in test scripts, but it also alters the string. If the original `source` came from a corpus file, the offsets in the dedented string **do not map automatically** to the original file.

## 4. Why normalization is dangerous for source offsets

Consider:

```python
original = '    hello\n    world\n'
clean = textwrap.dedent(original)
print(repr(original))  # '    hello\n    world\n'
print(repr(clean))     # 'hello\nworld\n'
```

The `w` in `world` has a different position in `clean` and `original`. If you calculate `MinimalSource` indices from `clean`, they will be incorrect for the real source file.

**Invariant:** For every chunk, `chunk.text == file_text[first_character_index:last_character_index]`.

## 5. Safe uses in the RAG project

- Format diagnostic text on the CLI.
- Create readable demonstrations in your documentation.
- Optionally generate a cleaned *indexing representation* (`index_text`) **after** calculating the original range. Keep `text` and `MinimalSource` tied to the original file.

Do not feel obliged to import `textwrap` in `chunking.py`; most first versions do not need it.

## 6. Exercises

**C.** You want to add a class name before a method to improve search ranking. Which field should hold that enriched text: `text` or `index_text`?
